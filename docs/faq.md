# FAQ

## 为什么 IK 在「直腿」位置解不出来？

直腿是奇异构型：脚在腿的最大伸展处，绕髋/膝的微小旋转一阶只改变 x、不改变 z
（cos 的一阶导为 0）。所以纯 z 方向的目标从直腿起解不动。解法：目标带前向分量，
或从微屈膝的初值起步。

## 为什么多机同步用 Kuramoto 而不是广播主时钟？

110 台机器人无法都连到单一主时钟（单点故障 + 无线抖动）。Kuramoto 弱耦合振子是
分布式共识模型：每台只和邻居对齐相位，就能自发锁到共同节拍，天然容错。

## 为什么训练信号不能「对 +1 错 -1」？

低起点 skill 下正确率 < 50%，随机游走的期望漂移为负，会把 skill 压到 0。几何爬升
`skill += lr(1-skill)` 恒正，保证单调。
