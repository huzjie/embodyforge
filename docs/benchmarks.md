# 基准说明

`python -m embodyforge bench` 跑 5 项：

| 基准 | 类型 | 口径 |
|---|---|---|
| balance | 结构 + 学习 | ZMP 在支撑多边形内的稳定裕度 @ skill 0.5 / 1.0 |
| sync | 学习 | Kuramoto 序参量 r（相位锁定程度）@ 0.5 / 1.0 |
| gait | 学习 | 行走稳定性 = 1 - 跌倒率 @ 0.5 / 1.0 |
| skill_recall | 学习 | 具身基础模型技能召回 recall@1 @ 0.5 / 1.0 |
| speedup | 结构 + 学习 | 多机协同并行加速（Amdahl 上界）@ 0.5 / 1.0 |

学习项从随机基线单调爬向最优；结构项是固定属性。skill=0.5 恰随机、1.0 恰完美。
